About the Project

The AI Resume Screening & Analysis System is a project that helps students and job seekers evaluate their resumes against a job description using machine learning and NLP — without relying on any external AI APIs.

Technology Used
  • Frontend: HTML5, CSS3, Bootstrap 5, JavaScript, Chart.js, Font Awesome, Google Fonts (Poppins)
  • Backend: Python Flask
  • Database: MySQL (database resume_screening, table resume_data)
  • ML/NLP: scikit-learn (TF-IDF + Cosine Similarity), spaCy, NLTK
  • Resume parsing: pdfplumber, python-docx
  • PDF Report: reportlab
